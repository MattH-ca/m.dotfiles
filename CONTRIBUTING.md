# Contributing

Thanks for taking an interest in these dotfiles.

This repo is public so you can read it, learn from it, and fork it freely.
It is my personal machine configuration, published as a reference rather than as a project, so it does not take outside contributions of any kind.

## What this repo does not accept

- **Pull requests.** They are auto-closed, including bug-fix PRs.
- **Feature requests.**
- **Bug reports.** Issues are turned off here.

That is not meant as a brush-off. A personal setup only stays useful if it keeps matching one machine, and an inbox of requests to generalise it works against that.

## What to do instead

Fork it and make it yours.
Everything is threaded from a single `user` line in `flake.nix`, and `README.md`'s "Make it yours" section lists the handful of things to change before your first build.

If something here is broken in a way that would bite anyone who cloned it, the fix is to correct it in your fork.
Nothing here is precious, and MIT No Attribution means you owe nothing back.
